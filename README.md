## 🚀 GitHub & Vercel 배포 방법

이 프로젝트는 Vite + React 기반 정적 SPA로 빌드되어 GitHub와 Vercel에 가장 이상적으로 배포됩니다.

### 1. GitHub 업로드
```bash
git init
git add .
git commit -m "feat: Asi.K official portfolio website"
git branch -M main
git remote add origin https://github.com/your-username/asik-portfolio.git
git push -u origin main
```

### 2. Vercel 배포
1. [Vercel](https://vercel.com)에 로그인 후 **"Add New..."** > **"Project"**를 선택합니다.
2. 위에서 생성한 GitHub 리포지토리를 Import 합니다.
3. Framework Preset은 **Vite**로 자동 감지됩니다 (`vercel.json` 설정 포함).
4. **Deploy** 버튼을 누르면 약 30초 내에 전 세계 CDN을 통해 라이브 배포가 완료됩니다.
